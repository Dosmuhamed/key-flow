# KeyFlow — тренажёр слепой печати

Фронтенд-приложение без бэкенда: React 19 + TypeScript + Vite + Tailwind CSS v4 + lucide-react.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Возможности

- **Языки и раскладки:** русский (ЙЦУКЕН), английский (QWERTY), казахский, немецкий (QWERTZ), испанский.
- **Режимы:** на время (15 с – 2 мин), на количество слов, связный текст, уроки по рядам клавиатуры и урок «Мои ошибки» по самым трудным буквам.
- **Опции:** знаки препинания и заглавные, цифры, строгий режим «Без ошибок», скорость в зн/мин или сл/мин, светлая и тёмная тема.
- **Подсказки:** экранная клавиатура (вид Mac или PC выбирается автоматически по ОС), подсветка следующей клавиши и Shift, подсказка пальца, предупреждение о неверной раскладке.
- **Отчёт:** скорость, точность, ритмичность, график по секундам, покадровый повтор прохождения, тепловая карта клавиш (ошибки и время нажатия), точность по буквам, работа пальцев, частые промахи, медленные слова, советы.
- **История** результатов и статистика по буквам хранятся в `localStorage`.

Горячие клавиши: `Tab` — новый текст, `Esc` — начать этот текст заново, `⌥ + delete` на Mac или `Ctrl + Backspace` на Windows — стереть слово.

## Структура

```
src/
  data/          языки, словари, тексты, раскладки клавиатуры
  lib/           генерация текста, аналитика, хранение, форматирование
  hooks/         useTypingTest — движок набора и запись нажатий
  components/    экран набора, клавиатура, руки, отчёт
```
